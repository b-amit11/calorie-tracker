# Web app

Next.js app for the calorie tracker. See the [project README](../README.md) for the overview, and [docs/DESIGN.md](../docs/DESIGN.md) for the design notes.

```bash
npm install
npm run dev          # http://localhost:3000
npm test             # Vitest
npm run typecheck
npm run db:generate  # create a migration after editing lib/db/schema.ts
```
